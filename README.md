Employee Clock-In System

  User Authentication: Login system with separate access for standard employees and administrators.

  Live Digital Clock: Real-time clock displaying the time.

  Clock In / Clock Out Tracking: Logs exact clock-in/out timestamps and automatically computes total hours worked.

  Admin Dashboard: A structured table (ttk.Treeview) giving managers a full overview of all employee records and logged hours.

Tech Stack
    Language: Python 3
    GUI Framework: Tkinter
    Database: SQLite3
